# flowpath-app — Лендинг-портфолио

Одностраничный сайт-портфолио для AI-креатора и контент-менеджера.

## Стек

- **React 19** + **Vite 8**
- **Tailwind CSS 4**
- **Lucide React** (иконки)

## Функции

- Fullscreen hero с фоновым видео
- Адаптивная навигация (мобильное меню с glass-эффектом)
- Секция портфолио: асимметричная сетка карточек 3:4, при наведении/тапе — замена webp на mp4
- FAQ-аккордеон
- Футер с контактными кнопками (Kwork, Telegram)

## Разработка

```bash
npm run dev      # dev-сервер
npm run build    # продакшн-сборка
npm run preview  # предпросмотр сборки
```
